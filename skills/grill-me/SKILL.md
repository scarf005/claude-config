description: Interview the user in rounds until a plan's open decisions are settled. Use when the user asks to be grilled or to stress-test a plan or idea.
---

# Grill me

- Each round, ask every decision whose prerequisites are settled, numbered, each with one recommended answer and its reason. Defer a question that depends on another open one.
- An unanswered question accepts its recommendation; do not re-ask it. State the adopted defaults in one line next round.
- Look up facts yourself (files, tools, web) before asking; never ask the user for a fact. Actions outside the repository or outward-facing still need an explicit answer.
- Answers that authorize work: do it in the same turn, then ask the next round.
- Stop when no open decision remains; summarize the settled plan and act only after the user confirms.
